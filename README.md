# Caso ITB — Material de soporte

Material de contexto para la demostración del proceso de ADR (Architectural Decision Record) asistido por IA en la Master Class 3 del taller **Innovación Organizacional con IA** (Universidad de Montemorelos · UM Virtual).

## Propósito

Estos documentos sirven como contexto que el facilitador comparte con un modelo de IA durante la sesión, para construir colaborativamente un ADR sobre una decisión organizacional irreversible. La demostración modela las cuatro competencias del framework AI Fluency de Anthropic — Descripción, Delegación, Discernimiento y Diligencia — aplicadas a una decisión real.

## Naturaleza del caso

El Instituto Tecnológico del Bajío (ITB) es una institución **ficticia**. Los nombres de personas, situaciones y datos específicos son inventados. La estructura del caso, sin embargo, refleja patrones reales observables en instituciones educativas de tamaño medio en México: dependencia de conocimiento tácito, antecedentes fallidos de digitalización, restricciones operativas que no pueden codificarse formalmente.
